The chores

Renting a box takes a minute. Making an agent live on it doesn’t.

None of this is hard. All of it is fiddly, none of it is interesting, and you do every bit of it again for the next machine.

By hand

Edit ~/.ssh/config and hope

An Include won’t do. Codex parses that file with a library that never expands them, so a host behind one is invisible and you get no error explaining why.

Codex Remote

The block is written where it’s read

Inline, above your Host * so first-match can’t override it, inside markers it can remove again cleanly.

By hand

Install, log in, answer the wizard

Node, the CLI, an OAuth round trip, then a first-run prompt that blocks forever under a service manager because nobody is there to pick a theme.

Codex Remote

Bootstrapped and signed in

Wizards pre-answered. Claude Code runs as its own claude user with its own login, never a copy of your Mac’s — two installs can’t share one refresh token.

By hand

Keep a terminal open

Close the lid and lose the session. Reboot the box and find out days later that the agent never came back.

Codex Remote

Units, enabled at boot

Everything it installs shares one prefix, so systemctl status 'codex-remote-*' shows the lot — and a stop/start brings all of it back.

By hand

Leave your MCP servers behind

The remote agent is a stranger to every tool you’ve already wired up.

Codex Remote

They travel

Portable servers are copied over. Ones that point at a path only your Mac has are left behind deliberately, and it names each one and why.

What it does

Four stages, then it’s yours.

01

Create

OpenTofu applies a small per-cloud module and makes one server with your key on it. Each machine gets its own state file, so one can never disturb another.

02

Bootstrap over SSH

Base packages, the Codex CLI at /usr/local/bin/codex, Claude Code under its own account, your MCP servers, and a systemd unit for each agent.

03

Register

A Host codex-remote-<name> block goes into your SSH config — which is how the Codex app finds a machine and starts codex app-server on it over SSH.

04

Connect

Codex picks it up under Connections. Claude Code dials out and appears in your account. Pair it once and the box answers from your phone too.

Install

Bring your own cloud.

Hetzner, AWS, DigitalOcean, Linode, Vultr or Scaleway. You pay them directly — there is no service in the middle, and no account to make here.

Homebrew

Keeps up to date with brew upgrade.

$ brew install --cask pandelisz/tap/codex-remote
  • macOS 15 (Sequoia) or later
  • Apple silicon or Intel

Direct download

Ad-hoc signed, not notarised. macOS calls a downloaded copy “damaged” until the quarantine flag is removed — Homebrew does that for you.

Latest release
  • Unzip, drag to Applications
  • xattr -dr com.apple.quarantine /Applications/CodexRemote.app
  • Lives in the menu bar, not the Dock
$ codex-remote create --account hetzner --name my-box

The CLI ships inside the app. Everything the menu bar does is scriptable, and the reverse.
