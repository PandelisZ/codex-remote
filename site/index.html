Your coding agent, on a machine that isn't your laptop.

Give Codex Remote a cloud provider token. It builds the server, installs Codex and Claude Code, brings your MCP servers along, and the machine turns up where you already work — no SSH config to hand-edit, nothing to keep alive in a terminal.

Renting a box is easy. Making an agent live on it isn't.

Every remote-agent setup runs into the same handful of chores. None of them are hard. All of them are fiddly, and you do them again for every machine.

Hand-edit ~/.ssh/config

And find out the hard way that an Include doesn't count — Codex parses that file with a library that never expands them, so your host is invisible.

The host block is written for you

Inline, above your Host *, inside markers it can cleanly remove again. Codex finds it on next launch.

Install and authenticate on every box

Node, the CLI, a login, the first-run wizard that blocks forever under a service manager because nobody is there to pick a theme.

Bootstrapped and signed in

Agents installed, wizards pre-answered, Claude Code under its own non-root account with its own login — never a copy of your Mac's.

Keep something running in a terminal

Close the lid, lose the session. Reboot the box and quietly discover the agent never came back.

systemd units, enabled at boot

Everything it installs comes back after a stop/start. One prefix, so systemctl status 'codex-remote-*' shows the lot.

Your MCP servers stay behind

The remote agent is a stranger to every tool you've configured locally.

They come with it

Portable servers are carried over; ones that only exist on your Mac are left behind on purpose, and it tells you which and why.

What happens when you add a machine

1

Create

OpenTofu applies a small per-cloud module and makes one server with your key on it. Each machine gets its own state, so one can never disturb another.

2

Bootstrap

Base packages, the Codex CLI, Claude Code under its own account, your MCP servers, and a systemd unit for each — all over SSH.

3

Connect

Codex finds the host in your SSH config and starts its app-server there itself. Claude Code dials out to your account. Pair it to reach the box from your phone.

Install

Bring your own cloud account — Hetzner, AWS, DigitalOcean, Linode, Vultr or Scaleway. You pay them directly; Codex Remote has no service in the middle.

Homebrew

The tap keeps it updated with brew upgrade.

$ brew install --cask pandelisz/tap/codex-remote
  • macOS 15 (Sequoia) or later
  • Apple silicon or Intel

Direct download

A notarised build is attached to every release.

Download the latest release
  • Unzip and drag to Applications
  • It lives in the menu bar, not the Dock

Prefer the terminal?

Everything the menu bar does is scriptable, and vice versa.

$ codex-remote create --account hetzner --name my-box
